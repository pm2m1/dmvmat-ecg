## Part 2: stronger baselines

For each budget and nine episodes, include original source-only and full fine-tuning, plus:

1. AdaBN only: zero labels and zero optimizer updates. Clone the source, reset BN running mean/variance/counter, set BN momentum=None, make exactly one deterministic signal-only pass through U (seed 20261125, batches 32, last partial batch retained). Keep all parameters frozen and dropout in eval; only BN modules train. Use source normalization. Every BN layer recomputes running statistics with its actual preceding layers under this pass. This streaming cumulative BN rule is explicit, not exact whole-population variance. One fitted BN state per source seed is reused for all budgets/draws; no adapted model checkpoint is saved.
2. AdaBN + full: same BN pass then 200 ordinary full updates, same original target seed.
3. LP-FT: head-only for 50 updates, then all modules for 150 updates; total 200. Preserve head AdamW moment state at transition; initialize moments for newly trainable parameters at update 51. Reuse one original sampler/RNG stream across both stages; no RNG restart or LR reset. Head-only stages preserve backbone BN buffers.
4. L2-SP: full optimization with BCE + alpha times the SUM of squared differences of all model parameters from source initialization (head included; buffers excluded), alpha in {1e-4,1e-3,1e-2}. Choose one alpha per budget by mean A macro AP over nine episodes, exact ties toward smaller alpha. Never choose per episode or using B.

Zero-shot and AdaBN-only are three distinct source vectors, not nine independent fits; repeat their vectors only to align paired nine-episode means. Their results are identical across nominal labeled budgets and must be labeled 0 optimization labels. Refit full comparators under the exact recipe; verify B128 state/drift/final loss against bundle references.

Report fold9 AP/AUROC and selected epoch for original and aligned sources.

Loss: observed-label BCE(source batch) + lambda * SUM over seven modules of differentiable multi-kernel MMD(source representations, signal-only U batch). Both domains pass through the same train-mode source model, source first then target; dropout/BN are active as in training and target contributes no labels. Cycle a seeded target randperm stream (seed namespace [20261126,source_seed]) into 32-record batches. Do not change the source sampler/RNG seed; target sampling uses its own Generator. Use a biased nonnegative V-statistic, including diagonal entries; average four Gaussian RBF kernels with bandwidth multipliers {.5,1,2,4} around the detached positive pairwise-distance median of the combined source/target representation batch. Define kernel exp(-squared_distance/(2*sigma_squared)), with sigma_squared equal to median squared distance times multiplier squared. Detach only bandwidth estimation, never representations or MMD gradients; fail on nonfinite evidence. This is a declared DMV-MAT-inspired alignment variant, not a claimed exact paper reproduction. Zero dispersion uses a fixed epsilon scale without interpreting labels.

Lambda selection: first require mean fold9 macro AUROC no more than .05 below the original-source mean and both label AUROCs above .5 for every source seed. This prespecified engineering collapse screen is not a clinical margin. Among passing lambdas, choose highest mean A macro AP after ordinary B128 full fine-tuning across all nine episodes; ties use higher mean fold9 AUROC then smaller lambda. If neither passes, retain the original-source default recommendation and explicitly flag source collapse. To complete all requested benchmark arms, use a descriptive fallback lambda maximizing mean fold9 AUROC, then mean A AP, then smaller lambda; still run its zero-shot/full/selector arms. A target AP win does not erase failure of source preservation, and no successful noncollapsed alignment may be claimed in this case. B is never read for this choice.
